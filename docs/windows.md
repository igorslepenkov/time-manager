# Windows

## Требования

- Windows 10 или 11.
- [rustup](https://rustup.rs) со стабильным тулчейном.
- Права администратора не нужны.

## Сборка

```powershell
cargo build --release
```

Готовый файл — `target\release\sc-time-manager.exe`. CRT слинкован статически (`.cargo/config.toml`), поэтому Visual C++ Redistributable не требуется.

## Запуск

Запускайте exe из папки, доступной на запись: `Program Files` не подходит. При первом запуске рядом появляются `config.json` (настройки), `state.json` (текущий день) и `sc-time-manager.log` (журнал).

Рабочую копию удобно держать в отдельной папке `dist` — она в `.gitignore`:

```powershell
mkdir dist
copy target\release\sc-time-manager.exe dist\
```

После пересборки закройте приложение и скопируйте новый exe в `dist` поверх старого. Настройки и текущий день не пострадают.

## Окно

Windows 11 по умолчанию открывает консольные программы в Windows Terminal, поэтому exe запустится вкладкой Terminal. Если нужно отдельное классическое окно, используйте ярлык через `conhost.exe` — он описан в разделе «SmartScreen».

Рекомендуемый размер окна — 120×30, минимальный — 80×24: при меньшем окне приложение попросит его увеличить.

## SmartScreen

При запуске неподписанного exe Проводник может показать «Система Windows защитила ваш компьютер». Это Microsoft Defender SmartScreen: у файла нет подписи и репутации. Сообщение не означает, что в файле вирус.

Варианты:

1. **Подписать exe** — надёжно, но нужен сертификат, см. «Подпись».
2. **Отключить проверку приложений и файлов** — быстро, но защита ослабевает для всех программ: Параметры → Конфиденциальность и защита → Безопасность Windows → Управление приложениями и браузером → Защита на основе репутации → Параметры.
3. **Локальный обход через `conhost.exe`** — без изменения настроек, но работает только при запуске через ярлык.

### Ярлык через conhost.exe

Проводник проверяет подписанный `conhost.exe`, а тот уже запускает наш exe. Поэтому предупреждение не появляется, а окно остаётся классическим.

1. Правый клик по `sc-time-manager.exe` → «Создать ярлык».
2. Правый клик по ярлыку → «Свойства».
3. В поле **«Объект»** впишите `C:\Windows\System32\conhost.exe "D:\путь\к\dist\sc-time-manager.exe"`: здесь указываются и программа, и её аргумент. Путь к exe — в кавычках.
4. В поле **«Рабочая папка»** укажите папку с exe.
5. Нажмите «ОК» и закрепите ярлык на панели задач.

Ограничения:

- двойной клик по самому exe по-прежнему откроет Windows Terminal и может показать предупреждение;
- заголовок окна берётся из имени ярлыка;
- после переноса папки ярлык нужно пересоздать.

### Подпись

Нужен OV- или EV-сертификат подписи кода либо Azure Trusted Signing. Самоподписанный сертификат не помогает: SmartScreen смотрит на репутацию, а не на факт подписи.

`signtool` входит в Windows SDK:

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /f cert.pfx /p <пароль> dist\sc-time-manager.exe
```

Подписывать нужно каждую сборку. Дешёвые варианты: Certum для открытых проектов (около 30 € в год) и SignPath Foundation для open-source (бесплатно).

## Перенос на другой компьютер

Скопируйте `sc-time-manager.exe`, `config.json` и `state.json`. Папку `themes/` — только если в ней есть ваши темы: `config.json` и `state.json` создадутся заново, а папка тем — нет.

## Если что-то не работает

- **`VCRUNTIME140.dll` не найден** — сборка сделана без статического CRT. Пересоберите проект, чтобы применился `.cargo/config.toml`.
- **Предупреждение вернулось после пересборки** — это ожидаемо: у нового файла нет истории запусков.
- **Причина ошибки** — в `sc-time-manager.log` рядом с `config.json`.
