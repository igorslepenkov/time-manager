# Настройки и выгрузка

## config.json

Файл лежит рядом с exe и создаётся при первом запуске. Правки применяются при следующем запуске; если файл повреждён, приложение показывает предупреждение и сохраняет копию `config.json.broken`.

| Поле | По умолчанию | Назначение |
|---|---|---|
| `language` | `"en"` | язык интерфейса: `en` или `ru` |
| `theme.preset` | `""` | имя темы; пусто — `Default` |
| `export.sheet_name` | `"%d.%m.%Y"` | формат даты для имени листа и файла |
| `export.output_dir` | `""` | папка выгрузки; пусто — рядом с exe |
| `export.totals_enabled` | `true` | итоговая строка |
| `export.totals_label` | `"Итого"` | подпись итога |
| `export.open_after_export` | `false` | открыть файл после сохранения |
| `export.font_name` | `"Nunito"` | шрифт ячеек |
| `export.font_size` | `10` | размер шрифта |
| `export.text_color` | `"#000000"` | цвет текста |
| `export.background_color` | `"#EEEEEE"` | фон ячеек |
| `export.header_enabled` | `false` | шапка таблицы |
| `export.header_bold` | `true` | жирная шапка |
| `export.header_background_color` | `"#DDDDDD"` | фон шапки |
| `export.row_height` | `50` | высота строки в пунктах |

`output_dir` понимает `%USERPROFILE%` и начальный `~`; относительный путь считается от текущей рабочей папки. Двоеточия и другие запрещённые символы в имени файла заменяются на дефисы.

## Колонки

`export.columns` — список колонок по порядку. Поле `kind` задаёт содержимое:

| `kind` | Содержимое |
|---|---|
| `date` | дата |
| `tag` | тег |
| `task` | задача |
| `start`, `end` | начало и конец |
| `duration` | длительность |
| `hours` | часы |
| `empty` | пустая колонка-разделитель |

Необязательные поля колонки: `title`, `width`, `num_format`, `wrap`, `bold`, `formula`. В формулах доступны подстановки `{row}`, `{start}`, `{end}`, `{duration}`.

По умолчанию: Дата, Тег, Задача, Начало, Конец, Длительность, Часы.

Формулы записываются вместе с посчитанным результатом, поэтому значения видны сразу — в том числе при копировании «только значений» в Google-таблицу.

## Темы

16 тем встроены в бинарник. Свои темы кладутся в папку `themes/` рядом с exe, по файлу на тему:

```json
{
  "name": "Моя тема",
  "colors": {
    "background": "#101018",
    "text": "#E8E8F0",
    "muted": "#707088",
    "panel": "#1C1C2A",
    "panel_text": "#E8E8F0",
    "accent": "#00C8FF",
    "accent_text": "#101018",
    "border": "#303048",
    "error": "#FF5F5F"
  }
}
```

Правила:

- имя встроенной темы занять нельзя — такой файл пропускается;
- из двух файлов с одинаковым именем побеждает первый по алфавиту;
- битый файл пропускается, остальные загружаются;
- если ролей не хватает, тема грузится с умолчаниями, но приложение предупредит.

Список перечитывается при каждом открытии вкладки `Config`.

## Служебные файлы

| Файл | Назначение |
|---|---|
| `state.json` | текущий день |
| `state.cleared-<дата>.json` | копия дня перед сбросом |
| `state.json.<pid>.tmp` | временный файл; из него восстанавливается день после обрыва записи |
| `config.json.broken` | повреждённый конфиг |
| `sc-time-manager.log` | журнал статусов и ошибок |
